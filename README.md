💻 Personal Web Development Portfolio

Welcome to my personal developer portfolio repository! This repository contains the source code for my portfolio website, showcasing my full-stack web development projects, technical skills, and practical experience.

---

## 🌟 Highlights & Features

* **Project Showcases:** Interactive cards and demos highlighting key projects (e.g., Real Estate Portal, E-Commerce, Vehicle Portals).
* **Skills Overview:** Categorized section for front-end, back-end, and database technologies.
* **Fully Responsive:** Optimized for desktop, tablet, and mobile screens.
* **Contact Integration:** Easy ways to connect via email, GitHub, and LinkedIn.

---

## 🛠️ Tech Stack & Tools

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend:** Python
* **Database Management:** MySQL / XAMPP
* **Tools & Environment:** Git, GitHub, VS Code
